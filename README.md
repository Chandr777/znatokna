# Знатные окна

Статическая сборка сайта для переноса на самостоятельный хостинг.

Актуальная сборка и документы находятся в архиве релиза (`znatnye-okna-site.tar`). Распакуйте архив и загрузите содержимое каталога `dist` в корневую папку сайта на хостинге. Главная страница — `index.html`.

Источник: проект ChatGPT Sites, версия 18.
